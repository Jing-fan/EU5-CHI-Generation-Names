# 天朝宗族字辈命名 (CHI Generation Names)

为 *Europa Universalis V* 的天朝皇室引入中国传统的二十字辈宗族命名体系。天朝领袖可通过决议与事件链，为本朝宗室钦定专属命名规制与二十字辈谱系，令此后世代子孙按辈序名、昭穆分明。

## 核心功能与玩法

### 1. 启用方式与流程

满足以下条件时，可在决议面板中执行 **「钦定宗室字辈」**：

- **可见条件**：属于天朝国际组织（`middle_kingdom`）成员、当前统治者尚未确立字辈方案、且全局 7 套谱系尚未全部被占用。
- **执行条件**：当前国家为**天朝领袖**，且满足「中华文化组」或「汉化价值观 > 50」。

点击决议确认后，将依次弹出以下选择事件：

1. **钦定字辈规制**：在三大命名规制中选择其一（已被他朝占满的分支会自动隐藏）。
2. **钦定具体谱系**：从备选的二十字辈诗中择一颁行（世代同旁之制仅有一套，选定后直接进入下一步）。
3. **明定字辈礼制**：决定本朝宗室女眷是否一并按字辈赐名。

---

### 2. 三大命名规制（共 7 套二十字辈谱系）

所有谱系均包含 20 个字辈，满 20 代后自动从第 1 字重新循环：

- **行五行相生之制（2 套谱系）**
  - 为契合「木生火」之序，启用决议的始祖新出生的**儿子辈**男丁将先从木字旁字库取**单字名**；
  - 自**孙辈**起正式按选定的二十字辈诗排辈，男丁末字按 **火 → 土 → 金 → 水 → 木** 五行偏旁世代循环轮转（满 20 代后直接回环至第 1 字辈双字名，不再退回单字名）。
- **行世代同旁之制（1 套谱系）**
  - 自始祖新出生的**子辈**起直接按二十字辈诗排辈，每代男丁名字末字均配以该代专属偏旁（如示、日、玉、心、言等）。
- **行雅字通谱之制（4 套谱系）**
  - 自始祖新出生的**子辈**起直接按选定的二十字辈诗排辈，名字末字不限固定偏旁，从通用雅字库中择取。

---

### 3. 一些机制介绍

- **全局唯一互斥**：全游戏共 7 套二十字辈谱系，任一谱系被某朝选用后即在后续事件中自动隐藏，异姓改朝换代时不会撞谱；前朝残存宗室仍继续沿用其既有字辈。
- **各王朝独立女眷礼制**：每个王朝（按方案 `1~7` 独立记录）可单独决定宗室女眷是否按辈赐名，改朝换代不会互相覆盖。只要确立了宗室字辈，所有新出生的宗室女眷均直接从 **200 字专属女性雅字库**中择字（不回退原版姓名库、不受男性偏旁限制，也不占用男丁偏旁名额）：有字辈时取「字辈字 + 女性雅字」双字名，无字辈时（未开启女眷按辈赐名，或处于明式始祖之子辈尚未入辈）直接取单字名。
- **皇室近支保障与滑动冷却防重名**：
  - 全库内置 14 个独立抽号池（12 个偏旁池 + 1 个通用男字池各 100 字，1 个女性雅字池 200 字）与 48,000 条预拼接静态名键；
  - 采用步进滑动冷却机制（近支男丁锁 95 步、旁系锁 45 步、通用池锁 90 步、女性池锁 180 步），大幅降低同代重名概率；
  - 通过皇室近支判定与百年偏旁水位线动态分流，优先确保皇帝直系及近支皇子获得偏旁字，旁系在高水位时平滑回退通用雅字库。
- **AI 历史倾向与防断代保护**：
  - 朱姓天朝 AI 优先选择五行相生之制，女真文化天朝 AI 优先选择世代同旁之制；
  - 女性君主 AI 不主动启用决议；
  - 决议生效时会静默为国内现存同宗成员补齐代数，并在天朝换代中兜底防断代。

## 兼容性、存档与常见问题

- **兼容性**：本 MOD 全部为新增文件，通过 `on_actions` 挂载，**不覆写任何原版文件**。理论上与绝大多数不直接覆盖中国角色出生命名逻辑的 MOD 兼容。
- **中途加载**：支持在已有存档中随时启用。启用决议时**不会修改**现任君主与已出生宗室的名字，仅对决议生效后新出生的宗室成员自动命名。
- **语言限制**：目前仅提供简体中文本地化（`simp_chinese`）。
- **常见问题**：
  - **Q：启用五行相生之制后，为什么当前皇帝新生的儿子是单字名？**  
    A：这是特意还原的设定，以防止朱允炆变成朱元璋的儿子；统治者的下一辈没有字辈，再下一辈（即孙辈）才会从第 1 字辈 + 火字旁开始起名。
  - **Q：想在中途更改本朝是否对女性按字辈赐名怎么办？**  
    A：只能通过在控制台输入 `event zibei_events.3` 重新选择当前王朝的女眷赐名礼制。
  - **Q：只有这七套字谱吗？是否支持自定义字辈和续谱呢？**  
    A：很遗憾，一开始我的开发方向也是希望支持的，毕竟 CK3 已经有实现了这一功能的 MOD，但是目前来看 EU5 的引擎难以实现游戏内自定义的功能。如果要加只能修改 MOD 文件。
  - **Q：有些姓名实在是太离谱了，在哪里可以反馈呢？**  
    A：因为字库是随机生成，并且自由组合，所以有时难免会出现不合理的姓名。遇到这种情况可以在 Steam 或者 GitHub 反馈，只要我看到就会维护更新的。
